How the Copilot works

Transparency is part of good financial technology.

This hackathon prototype uses rules and arithmetic on data entered in this browser. It is not a live large language model, does not access bank accounts, and does not guarantee future spending. To add a real AI model later, connect a secure backend to an AI API and never expose API keys in this HTML file.
